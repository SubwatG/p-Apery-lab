# p-Apery-lab — p-Apéry Sets for Arithmetic Progressions

## Identity
Research notebook exploring **p-Apéry sets** for numerical semigroups generated by arithmetic progressions.
Goal: detect patterns → conjectures → formulas for generalized Frobenius numbers.

## Language
- **Primary:** ไทย — README, comments, notebook cells อธิบายภาษาไทย
- **English:** technical terms (p-Apéry set, numerical semigroup, Frobenius number), theorem names, variable names

## Tech Stack
- Python 3 — Jupyter Notebook (`.ipynb`)
- Libraries: `pandas`, `prettytable`
- Output: Excel (`.xlsx`) — experimental data tables
- Virtual env: `.venv/`

## Project Structure
```
see_pattern_of_pAp_onAP.ipynb   # Main research notebook
p_apery_table_a=5_d=*.xlsx      # Experimental output tables
README.md                       # Project overview + how to use
```

## Git Rules
- `.tex` และ `.pdf` **ห้าม commit** (ไม่มีใน project นี้ แต่เป็นกฎทั่วไป)
- อย่า commit `.venv/`, `__pycache__/`
- Data files (`.xlsx`) = experimental output — commit ได้ (เป็นผลลัพธ์ที่ reproduce ได้)
- Conventional commits

## Key Conventions
1. **Reproducibility:** notebook ต้อง clear แล้ว rerun ได้ — อย่า commit stale outputs ที่ run ไม่ได้
2. **Parameters:** `a` (initial term), `d` (common difference), `k`, `num_terms`
3. **Output naming:** `p_apery_table_a={a}_d={d}.xlsx`
4. **Research flow:** generate data → visualize patterns → conjecture → proof
5. **Execution required:** verify notebook outputs ก่อน claim pattern ใดๆ
